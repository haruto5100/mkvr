# マリオカートワールド VR管理システム

マリオカートワールドにおける個人のVR（レート）推移を記録し、実力の変化を可視化するための個人用Webアプリケーションです。ゲームプレイの妨げにならないよう、極めてシンプルかつ直感的なUI/UXを追求して設計されています。

**[アプリを開く（GitHub Pages）](https://haruto5100.github.io/mkvr/)**

## 主な機能

* **VRの迅速な記録**: 数値を入力するだけで、現在のタイムスタンプ（日時）とともに即座にデータを保存。
* **自己ベストの可視化**: 過去の最高VRを画面上部に常に表示し、モチベーションを維持。
* **推移のグラフ化**: 記録されたデータを折れ線グラフで視覚化。
    * 期間絞り込み機能搭載（「すべて」「1ヶ月」「1週間」）。
* **詳細な履歴表示**: 過去の記録を新しい順に一覧表示。
    * **差分表示**: 前回の記録からの増減値（+ / -）を自動計算してカラー表示。
    * **削除機能**: 誤入力したデータを個別に削除可能。
* **データのエクスポート / インポート**: 記録したデータをCSV形式でローカルに保存、または読み込みが可能（端末間のデータ移行やバックアップに対応）。

## 技術スタック

ビルド環境を必要とせず、ブラウザのみで軽量に動作する構成を採用しています。

* **フロントエンド**: HTML5, CSS3 (Vanilla), JavaScript (Vanilla)
* **グラフ描画ライブラリ**: [Chart.js](https://www.chartjs.org/) (CDN経由で利用)
* **データストア**: Local Storage (Web Storage API)
* **ホスティング**: GitHub Pages

## レスポンシブデザイン

PC、スマートフォン、タブレットのいずれの端末からでも快適に操作できるよう最適化されています。
* モバイル端末での意図しないダブルタップズームやフォーカスズームを防止するCSS設計。
* 押しやすいボタンサイズと十分な余白の確保。
